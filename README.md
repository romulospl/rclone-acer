# rclone-acer

Aplicativo OAuth **pessoal** usado pelo [rclone](https://rclone.org) para fazer o backup cifrado (restic) de um servidor doméstico na conta Google Drive do próprio dono.

- Usado por uma única pessoa: o dono desta conta.
- Escopo pedido: `drive.file` (o app só enxerga os arquivos que ele mesmo criou).
- Não é um produto nem um serviço oferecido a terceiros.

Política de privacidade: [PRIVACY.md](PRIVACY.md)

---

*Personal OAuth app used by rclone to back up the owner's home server to the owner's own Google Drive. Single user, `drive.file` scope only, not offered to anyone else.*
